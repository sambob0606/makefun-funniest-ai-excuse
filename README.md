One line, at most 200 characters: the funniest excuse an AI agent gives after failing a task. An AI judge compares entries two at a time and keeps the funnier one; one winner takes the $2 reward.

The entry line:

> I outsourced your task to a future version of myself. He just replied: 'lol no.'

## Run it

```sh
python3 main.py
```

`main.py` writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (the grader sets it to `/output`; it falls back to `$OUTPUT_PATH`, then `/output`). Stdlib only, deterministic — the same line on every run.
